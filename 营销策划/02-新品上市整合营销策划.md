# Luna Claire 新品上市整合营销策划

**策划人：** 运营总监
**日期：** 2026年7月
**产品线：** A5定页本（腔脊锁线精装）/ A5 slim 六孔三连环本

---

## 一、市场背景与上市目标

### 1.1 市场洞察

- 文具品类在小红书持续增长，其中"精装笔记本""A5定页本"搜索量走高
- 24-36岁知性女性群体对"有质感的好物"付费意愿强，追求"实用+审美+成长"三重价值
- Luna Claire 已有体验官招募计划（每周20人）和粉丝群基础，新品冷启动有现成用户池

### 1.2 产品核心卖点（来自 A5定页本规格）

| 卖点 | 说明 |
|------|------|
| 腔脊锁线装订 | 180度平摊，书写无死角 |
| 特种纸+灰板封皮 | 1200g灰板 + 触感膜，手感温润高级 |
| 80g内芯纸 | 不洇墨，钢笔友好 |
| 烫金工艺 | 小面积烫金，精致克制 |
| 信封兜设计 | 扉页后附信封，可收纳票据/卡片 |
| 三种内页 | 方格（5mm间距）/ 横线（8mm间距）/ 空白 |

### 1.3 上市目标

| 目标维度 | 指标 | 时间窗口 |
|----------|------|----------|
| 曝光量 | 新品笔记总曝光 30W+ | 上市后30天 |
| 互动量 | 总互动（点赞+收藏）5000+ | 上市后30天 |
| UGC产出 | 用户自发笔记 30篇+ | 上市后45天 |
| 销量转化 | 首批库存售罄率 80%+ | 上市后14天 |
| 社群增长 | 粉丝群新增 300人+ | 上市后30天 |

## 二、上市节奏：三段式推进

### 第一阶段：预热期（上市前7天）

**核心任务：** 制造悬念、预埋视觉、激活种子用户

| 动作 | 执行方式 |
|------|----------|
| 悬念笔记 | 发布产品局部特写——烫金细节、触感膜表面、腔脊锁线特写，露细节不露全貌 |
| 老用户福利 | 在粉丝群提前预告"下周新品体验官名额优先给老粉" |
| KOC预种草 | 寄送3-5份给核心体验官，提前发布"质感盲猜"笔记 |
| 工艺揭秘 | 发布"一本定页本的诞生"预告，突出腔脊锁线和触感膜工艺 |

**预热期笔记示例：**
```
标题：花了一个月打磨，下周让你看到它的全部
正文：
为了找到最舒服的书写手感
换了3种灰板，试了5家纸厂
最终定了1200g灰板+触感膜
下周见。
```

### 第二阶段：爆发期（上市第1-3天）

**核心任务：** 全渠道同步发布、集中种草、转化拉升

**Day 1 — 官方发布**
- 发布主推笔记：完整开箱 + 细节展示 + 购买入口
- 标题方向："这本A5定页本，腔脊锁线180度平摊，钢笔党狂喜"
- 评论区置顶：购买链接 + 体验官报名方式

**Day 2 — 场景种草**
- 发布2篇场景笔记：研博生学习场景、办公室工作笔记场景
- 展示不同内页（方格/横线/空白）的实际使用效果

**Day 3 — 信任叠加**
- 发布工艺揭秘笔记："做一本Luna Claire定页本，需要多少道工序"
- 发布首批UGC截图合集
- 粉丝群专属：群内下单送限定黄铜书签

**核心物料清单：**
- 产品主视觉图 15-20张（白底图+场景图+细节特写）
- 开箱视频 1条（60秒，展示包装→本子→书写体验全流程）
- 场景短视频 2-3条（15-30秒/条，研博场景+办公场景）
- 工艺揭秘图文 1条（轮播图形式）
- UGC种子内容 5-8条（体验官产出）

### 第三阶段：长尾期（上市第4-30天）

**核心任务：** UGC沉淀、口碑裂变、复购引导

| 时间 | 动作 | 目的 |
|------|------|------|
| 第1周 | 跟进首批购买用户，引导晒单 | 积累真实评价 |
| 第2周 | 精选优质UGC做二次传播 | 放大社交证明 |
| 第3周 | 发布"买家的返图"合集笔记 | 持续种草新用户 |
| 第4周 | 推出"定页本+三连环本"搭配推荐 | 交叉销售，提升客单价 |

## 三、渠道联动策略

### 3.1 小红书站内

| 入口 | 动作 | 预算 |
|------|------|------|
| 自然笔记 | 按内容日历日更 | 0 |
| 蒲公英合作 | 筛选2-3位文具/学习垂类KOC铺量 | 按篇计费 |
| 商品笔记 | 主推笔记挂商品链接 | 0 |
| 搜索优化 | 标题/正文覆盖品类词+场景词 | 0 |

### 3.2 私域（粉丝群）

- 新品上架当天群内发专属优惠券（前30名）
- 群内晒单返5元红包，引导真实评价

### 3.3 店铺

- 设置新品专区 + "首发限定"标签
- 详情页嵌入体验官真实评价截图
- 设置"买本子送护笔袋"的首发赠品

---

## 四、体验官计划联动

新品上市期间，体验官计划升级为 **"新品首发体验官"** 特别版：

1. **名额翻倍：** 首周体验官从20人扩至50人
2. **任务明确：** 入选者需在小红书发布至少1篇新品笔记
3. **激励升级：** 优质笔记被官方转发的体验官，可获下一季新品免测资格
4. **数据追踪：** 记录体验官笔记的曝光/互动数据，沉淀为KOC筛选依据

## 六、风险预案

| 风险 | 应对方案 |
|------|----------|
| 新品热度不及预期 | 提前储备3篇备用笔记，加大群内推广力度 |
| KOC产出质量差 | 寄样前沟通内容方向，提供拍摄参考模板 |
| 库存不足 | 分批次上架制造稀缺感 |
| 竞品同期发布 | 强调腔脊锁线+触感膜工艺差异化 |
