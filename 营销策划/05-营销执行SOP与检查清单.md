## 二、小红书笔记发布检查清单

### 创作阶段

- [ ] 标题是否覆盖核心关键词？（品牌词/品类词/场景词至少1个）
- [ ] 正文是否有"种草钩子"？（场景痛点 / 审美吸引 / 功能卖点）
- [ ] 图片是否符合品牌视觉规范？（色调/构图/道具/质感）
- [ ] 是否避开违禁词？（抽奖/免费送/好评返现等）
- [ ] 是否添加正确的话题标签？（3-5个）
- [ ] 是否挂载购买链接 / 引流入口？

### 发布后

- [ ] 发布后1小时内回复前10条评论
- [ ] 评论区引导互动："你平时用本子做什么？"
- [ ] 记录数据：24h/48h/7天的曝光-互动率
- [ ] 优质评论截图保存

## 三、体验官活动执行清单

### 周一（预告）
- [ ] 粉丝群发布本周体验官预告
- [ ] 更新群公告中的报名方式
- [ ] 检查引流笔记是否按时发布

### 周二至周三（收集）
- [ ] 群内@新成员提醒活动
- [ ] 私信发送问卷链接
- [ ] 已填问卷分类整理（按认真程度打标签）

### 周四（公布）
- [ ] 核对筛选标准：开放题认真 / 愿分享 / 画像匹配
- [ ] 过滤重复报名（昵称+地址+手机号三重校验）
- [ ] 19:00前确认最终名单
- [ ] 20:30 群内@公布入选者
- [ ] 私信发送购买链接（9.9元邮费链接）
- [ ] 开通链接30份，截止22:00
- [ ] 未入选回复："每周都有机会，下次就到你"

### 周五（发货）
- [ ] 核对后台订单信息
- [ ] 打包：笔记本1本 + 10元现金（小信封装）+ 反馈引导卡
- [ ] 群里告知已发

### 跟进（收货后）
- [ ] 收货3天：私信询问使用感受
- [ ] 收货7天：引导发笔记/写评价
- [ ] 用户发布笔记后及时点赞+评论+转发
- [ ] 评价截图存档，标记优质评价待复用

## 六、月度复盘框架

### 内容复盘
- 本月哪3篇笔记数据最好？为什么？
- 哪类内容互动率最高（书桌美学/书写时刻/拆箱/UGC/工艺）？
- 评论区高频反馈是什么？

### 社群复盘
- 粉丝群增长 vs 目标
- 体验官报名/产出质量
- 群活跃度变化

### 转化复盘
- 曝光→点击→加购→下单转化漏斗
- 哪个渠道/哪篇笔记带来最多转化？
- 客单价、复购率

### 下月计划
- 下月重点节点/活动
- 需要优化的环节
- 资源需求（预算/KOC/物料）
