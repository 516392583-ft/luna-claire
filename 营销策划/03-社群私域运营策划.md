# Luna Claire 社群私域运营策划

**策划人：** 运营总监
**日期：** 2026年7月
**执行基础：** 体验官招募计划（已运行）+ 小红书粉丝群（已建立）

---

## 一、私域架构

```
Luna Claire 私域矩阵
├─ 小红书粉丝群（主阵地）
│   ├─ 功能：日常互动、体验官活动、新品预告、UGC激励
│   └─ 定位：轻运营、低门槛、用户不反感
├─ 微信个人号/社群（深度运营，第二阶段启动）
│   ├─ 功能：VIP福利、深度反馈、复购引导
│   └─ 定位：高价值用户沉淀，提升LTV
└─ 店铺粉丝/订阅（电商端）
    ├─ 功能：评价引导、上新通知
    └─ 定位：交易导向
```

> **当前重点：** 小红书粉丝群为主阵地。微信私域可在粉丝群稳定500人后启动。

## 二、粉丝群运营体系

### 2.1 群定位

| 要素 | 内容 |
|------|------|
| 群名 | Luna Claire · 书写与秩序 |
| 群价值观 | 真诚分享、热爱书写、共同成长 |
| 氛围调性 | 安静、克制、有内容、不刷屏 |
| 用户画像 | 24-36岁知性女性，重视生活秩序和个人成长 |

### 2.2 每日运营SOP

| 时间 | 动作 | 内容 |
|------|------|------|
| 每日 09:00 | 早安分享 | 一句有力量的话或一段摘抄，配一张书桌美学图 |
| 每日 12:00 | 午间话题 | 轻量互动，"你最近在读什么书？""今天的TODO完成了吗？" |
| 每日 21:00 | 晚间分享 | 一张复古质感图 / 一段文字 / 一个思考 |
| 每周一 | 体验官招募预告 | 公布本周体验官活动详情 |
| 每周二至三 | 报名收集 | 私信发送问卷链接 |
| 每周四 20:30 | 名单公布 | @入选者 + 同步说明流程 |
| 每周五 | UGC精选分享 | 展示本周优质用户笔记截图 |
| 每两周 | 主理人分享 | 产品设计故事 / 工艺知识 / 新品进度 |

### 2.3 进群引导流程

```
用户看到笔记 → 私信"想进群"
       ↓
自动回复：欢迎语 + 群二维码 + 群规简述
       ↓
进群欢迎语：
"欢迎来到 Luna Claire · 书写与秩序 🌙
这里是喜欢书写、热爱生活的女孩子们的小角落。
每周有新品体验官活动，群内专属福利优先通知。
进群记得看群公告哦~"
       ↓
群公告：体验官活动规则 + 本月重点活动
```

## 三、体验官计划升级版

### 3.1 当前体系（已运行）

| 环节 | 当前方案 |
|------|----------|
| 频次 | 每周1次，每次10-20人 |
| 参与条件 | 进群 + 填调研表 |
| 成本 | 约8.1元/本（含快递） |
| 产出 | 调研报告 + 评价积累 + UGC内容 |

### 3.2 新增：体验官成长体系

| 等级 | 条件 | 权益 |
|------|------|------|
| 🌙 见习体验官 | 首次参与 | 获体验产品1份 |
| 🌙🌙 资深体验官 | 参与2次+产出了优质反馈 | 新品体验优先权 + 专属福利 |
| 🌙🌙🌙 核心体验官 | 参与3次+，持续产出UGC | 免费获赠每季新品 + "联名共创官"邀约 |

### 3.3 UGC激励阶梯

| 内容质量 | 激励方式 | 标准 |
|----------|----------|------|
| 基础 | 群内点名感谢 + 下次活动优先 | 发布了1篇使用感受笔记 |
| 良好 | 基础 + 官方账号转发 | 笔记互动>50，照片质量好 |
| 优秀 | 良好 + 赠下季新品 | 笔记互动>200，内容有创意 |
| 卓越 | 优秀 + 小额稿费（50-200元） | 爆款笔记，互动>1000 |

## 五、数据追踪看板

| 指标 | 计算方式 | 目标值 |
|------|----------|--------|
| 粉丝群人数 | 群成员总数 | 首月200人 → 第三个月500人+ |
| 群活跃率 | 每周发言人数 / 总人数 | > 30% |
| 体验官报名率 | 报名人数 / 群人数 | > 15% |
| UGC产出率 | 产出内容人数 / 体验人数 | > 60% |
| 体验官复购率 | 体验后购买人数 / 体验总人数 | > 30% |
| 群内转私信率 | 私信互动人数 / 群人数 | > 20% |
